# Arslonbek & Shaxnozaxon Wedding Invitation

A premium interactive wedding invitation page built with HTML, CSS, and vanilla JavaScript.

## Features
- luxury invitation cover screen
- live countdown timer
- theme switcher (beige-gold, white-floral, burgundy-gold)
- background music toggle
- share button and calendar invitation download
- RSVP form and guestbook
- mobile-responsive modern layout

## Project structure
- `index.html` — main invitation page
- `MUSIQA_QOSHISH.txt` — installation instructions
- `.gitignore` — excludes local audio file from git

## How to use
1. Place your `azizam.mp3` file in this same folder.
2. Open `index.html` in a browser.
3. Press the "Taklifnomani ochish" button.
4. Music starts automatically after user interaction.

## GitHub Pages deployment
If you want to publish it on GitHub Pages:
1. Push this repository to GitHub.
2. Go to repository settings.
3. Open Pages.
4. Select the main branch and root folder (`/`).
5. Save.

## Note
The music file is intentionally not committed because audio files are binary and usually large. Add `azizam.mp3` locally before opening the page.
